## 💖 About the Project

**PrankVerse** is a fun, interactive prank website designed to surprise visitors with a series of increasingly ridiculous browser-based challenges.

What begins as a completely ordinary loading screen quickly turns into a hilarious experience. Chase a button that refuses to cooperate, scroll through absurd terms and conditions, survive an army of silly pop-ups, and celebrate the grand finale with a burst of confetti!

No complicated setup. No backend. Just pure frontend creativity and playful chaos. 🎉

## 🌸 Features

- 💻 **Fake Loading Screen** — Watch the progress bar fill up, reverse, and display increasingly suspicious messages.
- 🏃 **Runaway Button** — Try to click the button that keeps escaping around your screen.
- 📜 **Ridiculous Terms & Conditions** — Scroll through hilarious fictional legal text before the accept button unlocks.
- 🪟 **Popup Mayhem** — Encounter funny fake alerts, fictional prizes, and absurd notifications.
- 🎊 **Confetti Finale** — Reach the final prank reveal and celebrate with animated confetti.
- 🔄 **Replay Experience** — Restart the prank and experience the chaos all over again.
- 🎨 **Dark, Modern UI** — Enjoy a playful interface with smooth transitions and animated elements.
- ⚡ **Lightweight Frontend** — Built with plain HTML, CSS, and JavaScript without a framework or build step.

## 🎮 How It Works

1. **The Illusion Begins:** A loading screen pretends to initialize a system.
2. **The Chase:** A mischievous button keeps moving whenever you try to interact with it.
3. **The Agreement:** A fictional Terms of Service modal challenges you to read its ridiculous contents.
4. **Popup Chaos:** Clicking the fake alerts makes more pop-ups appear.
5. **The Big Reveal:** The experience ends with a prank reveal and a confetti celebration.

## 🚀 Getting Started

Run PrankVerse locally in just a few steps!

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. Enjoy the prank! 🎭

### Option 2 — Run with a Local Server

**Clone the repository:**

```bash
git clone https://github.com/Aleezy-code/PrankVerse.git
cd PrankVerse
```

**Start a local server using Python:**

```bash
python -m http.server 8000
```

Open your browser and visit:

```text
http://localhost:8000
```

> You don't need `npm install`, a backend server, or a build process for the current project.

## 🌐 Deploy for Free

You can publish PrankVerse using **GitHub Pages**:

1. Open your repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Click **Save** and wait for deployment.

Your website will be available at:

`https://aleezy-code.github.io/PrankVerse/`

*The URL assumes your GitHub username is `Aleezy-code` and your repository is named `PrankVerse`. It will work once the repository is created and GitHub Pages finishes deployment.*
